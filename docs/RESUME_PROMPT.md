# Minimal new-chat handoff

A new conversation does not need the old Living Ecology chat history. Use this prompt:

> Continue the Living Ecology development in `KiwiJururu/eco`. Treat the repository as the source of truth. Read `AGENTS.md`, `docs/PROJECT_STATE.yaml`, `docs/DESIGN_DECISIONS.md` and the active GitHub issue, then continue autonomously until that batch is technically green or a genuine user design decision is required. Do not advance to the next issue while the current batch has a known objective bug.

That is sufficient to recover the intended development workflow.
